# Orphanage Website

A professional orphanage/children's charity platform built with Laravel, Blade, Tailwind CSS, and MySQL.

## Project Goals
- Public-facing charity website
- Donation management
- Programs and impact stories
- Volunteer/contact forms
- Secure authentication
- Admin dashboard
- User and donation management
- Reports and analytics

## Planned Modules
1. Public website
2. Authentication and user profiles
3. Donations and donation records
4. Programs and campaigns
5. Stories/news
6. Volunteers and contact submissions
7. Admin dashboard
8. Users/roles/permissions
9. Reports and analytics
10. Settings and notifications

## Development
Target stack: Laravel + Blade/Tailwind CSS + MySQL.
